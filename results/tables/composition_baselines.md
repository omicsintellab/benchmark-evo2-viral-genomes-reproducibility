Generated by `code/05_figures/make_composition_table.py`. Population: **1,691** genomes with an assigned family, 217 families. Ridge probes, 5-fold x 3 repeats.

Answers R1 3.4 ("a 6-mer table is only one way to describe composition") and R2 #3 ("ORF count, longest ORF, ORF coverage, stop-codon density and six-frame coding potential should be included").
